# 🟢 Project 05: NTP Internet Clock & Precision Timekeeper

> Synchronize atomic time directly with pool.ntp.org servers over Wi-Fi. Features automatic daylight saving time (DST) calculations, epoch timestamps, formatted human-readable output, and drift tracking.

---

## 📋 Overview
- **Category**: Beginner (⭐ 1/5)
- **Supported Boards**: All ESP32 variants
- **Features**:
  - Uses ESP32 internal hardware SNTP client (zero external RTC hardware required!).
  - Formats 12-hour (AM/PM) and 24-hour military time.
  - Automatically handles timezone offsets (POSIX format).
