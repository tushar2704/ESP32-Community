# 🟢 Project 02: 2.4 GHz Wi-Fi Spectrum Scanner & Analyzer

> High-speed asynchronous 2.4 GHz Wi-Fi scanner displaying network BSSID, RSSI decibel levels, signal quality bars, channel frequency, encryption cipher, and beacon interval.

---

## 📋 Overview
- **Category**: Beginner (⭐ 1/5)
- **Supported Boards**: Classic ESP32, ESP32-S2, ESP32-S3, ESP32-C3, ESP32-C6
- **External Components Required**: None (Zero wiring!)
- **Primary Goals**:
  1. Audit local 2.4 GHz RF congestion and identify least-crowded Wi-Fi channels (1, 6, or 11).
  2. Parse WEP, WPA, WPA2, and WPA3 security protocols in beacon frames.
  3. Format clean tabular serial telemetry for war-walking and site surveys.

---

## 🔧 Requirements
- Any Wi-Fi enabled ESP32 board
- Micro-USB or USB-C cable
