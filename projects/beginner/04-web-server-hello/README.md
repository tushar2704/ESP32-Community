# 🟢 Project 04: Embedded Web Server & IoT Control Panel

> Host a modern, responsive HTML5 web server directly on the ESP32. Toggle GPIO pins, view live CPU/memory stats, and control your device from any phone, tablet, or browser on your local network.

---

## 📋 Overview
- **Category**: Beginner (⭐ 1/5)
- **Supported Boards**: Classic ESP32, ESP32-S2, ESP32-S3, ESP32-C3, ESP32-C6
- **Features**:
  - Embedded CSS dark-mode dashboard.
  - Zero external internet connection required (runs over local Wi-Fi or Access Point).
  - Real-time JSON telemetry endpoint (`/api/status`).
  - Interactive toggle button to control onboard LED.

---

## 🔧 Requirements
- ESP32 board
- Local Wi-Fi router (or connect to ESP32's Access Point)
