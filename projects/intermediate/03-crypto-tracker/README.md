# 🟡 Project INT-03: Live Crypto Price Ticker & Sparkline Tracker

> Real-time cryptocurrency price tracker monitoring Bitcoin (BTC), Ethereum (ETH), and Solana (SOL). Fetches live USD prices, 24-hour percentage change, market cap, and formats ASCII trend sparklines directly over Wi-Fi via the CoinGecko public API.

---

## 📋 Overview
- **Category**: Intermediate (⭐⭐⭐ 3/5)
- **Supported Boards**: All ESP32 variants (Classic, S2, S3, C3, C6)
- **Features**:
  - Direct HTTPS JSON requests to CoinGecko Simple Price API.
  - Formats live prices with dynamic color/arrow trends (▲ / ▼).
  - Tracks 24-hour price change percentage.
  - Zero external components needed (Serial monitor or optional OLED).
